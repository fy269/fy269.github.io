Kompetenz 02

Windows Server

Serveradministration mit PowerShell, Hyper-V, Active Directory und Gruppenrichtlinien.

Im Windows-Server-Labor habe ich eine breite Themenfolge von der Serveraufnahme und PowerShell über Virtualisierung und Netzwerkdienste bis zu Active Directory, Gruppenrichtlinien und Zertifikatsdiensten bearbeitet.

Was ich praktisch bearbeitet habe

  • Serverzustände mit grafischen Werkzeugen und PowerShell aufnehmen
  • Hyper-V-Umgebungen, virtuelle Maschinen und virtuelle Netze einrichten
  • DNS, DHCP, Dateifreigaben und Speicherfunktionen konfigurieren
  • Active Directory, Benutzer, Gruppen, Organisationseinheiten und Standorte verwalten
  • Gruppenrichtlinien erstellen, filtern und ihre tatsächliche Anwendung prüfen
  • PKI-, Zertifikats- und Wiederherstellungsschritte in einer Laborumgebung nachvollziehen

Beispiel: Richtlinienwirkung statt bloßer Erstellung

Bei Gruppenrichtlinien prüfe ich nicht nur, ob ein Objekt angelegt wurde. In einem Laborfall zeigte gpresult, dass ein WMI-Filter die Anwendung verhinderte. Die zugehörige Projektseite beschreibt den Diagnoseweg genauer.

Werkzeuge

PowerShell, Windows Admin Center, Hyper-V-Manager, Active-Directory-Verwaltung, Gruppenrichtlinienverwaltung und Windows-Server-Diagnosewerkzeuge.

Die beschriebenen Arbeiten habe ich in einer dokumentierten Lernumgebung umgesetzt.
